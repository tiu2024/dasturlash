# 13. Zamonaviy IT yo'nalishlari: Web, Mobile, Data Science, AI, DevOps, Cybersecurity

II bob. Zamonaviy IT yo'nalishlari va raqamli infratuzilma asoslari · 1 ta nazariy dars

## Bu mavzuda

- Web va Mobile dasturlash yo'nalishlari
- Data Science (ma'lumotlar ilmi) va ma'lumotlar bilan ishlash asoslari
- Sun'iy intellekt va Machine Learning (mashinani o'rgatish) tushunchalari
- DevOps, server va bulutli infratuzilma asoslari
- Cybersecurity va axborot xavfsizligi yo'nalishi

Ma'ruza materiallari tez orada shu yerda e'lon qilinadi.
