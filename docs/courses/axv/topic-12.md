# 12. Git va GitHub bilan tanishuv

II bob. Zamonaviy IT yo'nalishlari va raqamli infratuzilma asoslari · 4 ta amaliy dars

## Bu mavzuda

- Git va GitHub tushunchasi, Version Control tizimi
- Repository, commit, branch va README fayllari bilan ishlash
- GitHub akkaunt yaratish va loyihani repository'ga joylash
- Git asosiy buyruqlari: init, add, commit, status, log, clone, push, pull

Ma'ruza materiallari tez orada shu yerda e'lon qilinadi.
